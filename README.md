# Interactive Web Tribute ("For You")

Website interaktif dan responsif yang dirancang sebagai bentuk dedikasi/tribute personal dengan pengalaman visual yang menarik, animasi halus, dan antarmuka ramah pengguna.

---

## ✨ Fitur Utama

- **🎨 Desain Responsif**: Kompatibel dan proporsional diakses melalui perangkat seluler (smartphone), tablet, maupun desktop.
- **✨ Animasi Interaktif**: Efek transisi halus dan interaktivitas dinamis berbasis JavaScript.
- **⚡ Ringan & Standalone**: Dibangun menggunakan core web technologies murni tanpa dependensi berat, memastikan performa loading instan.

---

## 🛠️ Tech Stack

- **Markup**: HTML5
- **Styling**: CSS3 (Flexbox/Grid, Keyframe Animations)
- **Interactivity**: Vanilla JavaScript (ES6+)
